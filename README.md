# Space Adventures
![Alt text](images/icon.ico "a title")

In a universe dominated by the evil power of the Purple Empire (the bad guys), the **grey warrior** fights for freedom, traveling around the universe and escaping from the **Purple Empire**'s fleet. How long can this freedom last? Maybe a day, maybe two, but it will soon be gone, and his memory will be lost.
